## Project Overview

私域引流宝 (liKeYun_ylb) — a WeChat private-domain traffic tool (v2.4.6, MIT license). Plain PHP 7.4 + MySQL (PDO), jQuery 3.6.0, Bootstrap 4.0. No framework, no Composer, no build/lint/test tooling — the repo root *is* the web root.

## Setup / Deployment

- Deploy to an Apache/Nginx + PHP 7.4 server. There is no build step.
- Fresh install: visit `http://<domain>/install/` and fill in DB credentials + admin account. The installer generates `console/Db.php` (DB config) and `install/install.lock`, and creates all 29 tables. Delete the `/install/` directory afterward (per README).
- Admin panel: `http://<domain>/console/index/`.
- **`console/Db.php` is not in git — it is generated by the installer.** Every PHP file does `include '../Db.php'` (or `'../console/Db.php'`) and relies on `$config` with keys: `db_host`, `db_port`, `db_name`, `db_user`, `db_pass`, `db_prefix`, `folderNum`.

## Architecture

### Multi-stage redirect flow (the core concept)

Every generated code type (群活码/客服码/渠道码/短网址/中间页/多项单页) resolves through the same pipeline:

1. **Entry** — `s/index.php` (generic key lookup) or `s/dwz.php` (short URLs) receives `?key=...`, looks up the key across tables in priority order (`huoma_qun` → `huoma_kf` → `huoma_channel` → `huoma_tbk` → `huoma_tbk_mutiSPA` → `ylb_qun_bingliu`), then redirects to the feature page on that record's 入口域名: `<rkym>/[folder-prefix/]common/<feature>/redirect/?<idParam>=...`
2. **Feature page** — `common/<feature>/index.php` (features: `qun`, `kf`, `dwz`, `channel`, `zjy`, `shareCard`, `multiSPA`, `CarouselSPA`) validates the id, updates PV counters, and hands off to
3. **Middle page (中转页)** — `common/<feature>/redirect/index.php`, which runs the WeChat-specific logic (并流/merge counting, domain switching, UA branching) and finally redirects to the landing URL on the 落地域名.

Domains are stored per record as three fields: `*_rkym` (入口域名/entry), `*_ldym` (落地域名/landing), `*_dlym` (短链域名/short-link). The `folderNum` config value (1–4) controls the directory prefix inserted between the entry domain and `common/` — see `redirectURL()` in `s/dwz.php` / `s/index.php`.

### Console (admin backend)

`console/` is organized by module (`qun`, `kf`, `channel`, `dwz`, `tbk`, `kami`, `user`, `plugin`, ...). Conventions:

- **One PHP file per action, returning JSON** (e.g. `console/qun/createQun.php`, `getQunList.php`, `editQun.php`, `delQun.php`). The jQuery frontends (`index.html` + module JS) call these via AJAX.
- **Auth**: each endpoint calls `session_start()` and checks `isset($_SESSION["yinliubao"])` (session holds the username). Admin/user-group checks use `user_admin` and the `ylb_usergroup` table.
- **Canonical endpoint pattern** (see `console/qun/getQunList.php`): `header("Content-type:application/json")` → session check → include Db.php → PDO with prepared statements → JSON out, with `code` values 200 (ok) / 201 (not logged in) / 204 (empty) / 500 (error).
- **Two coexisting DB access patterns**: the legacy `DB_API` class (`console/DbClass.php`, SQL built by string interpolation) is still used by many pages; newer/updated code uses native PDO prepared statements. Per the README changelog, the project is migrating away from `DbClass.php` — **use native PDO prepared statements for new code**.
- **Table prefixes**: `huoma_` (core app) and `ylb_` (newer features: user groups, kami/card keys, 并流). All 29 tables are defined in `install/install.php`.
- **Runtime schema migration**: some endpoints check `SHOW COLUMNS ... LIKE 'x'` and run `ALTER TABLE` when missing (e.g. `longpress_num` in `getQunList.php`).
- Helper functions (`warnInfo`, `getSqlData`, `redirectHmPage`, `updateQunPv`) are defined **per page** and duplicated across `s/*.php` and `common/*/index.php` — there is no shared helper library; changes must be applied to every copy.
- Plugin apps live under `console/plugin/app/` (`FrameProxy`, `jumpWX`, `pluginSDK`), each a self-contained app.js/app.json/index.html bundle.
- Uploads go to `/upload/`; `console/public/publicConfig.php` derives `$imgPathUrl` from the current host + protocol.
